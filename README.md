# TabFlow
Context-aware Chrome extension (Manifest V3, React, TypeScript, IndexedDB).

## Setup
1. Install Node 18+ from nodejs.org
2. `npm install`
3. `npm run build`   (use `npm run dev` to rebuild on save)
4. Chrome -> chrome://extensions -> turn on Developer mode -> Load unpacked -> select the `dist` folder
5. Pin TabFlow. Click the icon for the popup; the Dashboard button opens analytics, tasks, planner, workspaces and settings.
After code changes, click the reload icon on the extension card.
